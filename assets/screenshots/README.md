# Screenshots

`home-ready.png` and `backup-complete.png` are native Retina captures (1520 × 1440) of the Sound Backup 0.2.0 packaged Tauri app at its default 760 × 720 point window size. The `.webp` files are their lossless web versions with the display ICC profile retained.

Both were captured from the actual app using the apps website's Cocoa view capture helper, in an ignored private copy. A local Mic-Wise ran with synthetic audio and a demo show, "Spring Musical". `backup-complete.png` shows a real backup of that show into a temporary `Show Backups` folder; the helper pressed the app's own Back up button. No interface controls, connection statuses or results were fabricated. Avantis, QLab and SLink-Rack were not configured during capture. No account names, addresses or personal paths appear in the published captures. The window was inactive in `backup-complete.png`, so macOS drew its traffic lights grey.

The injected capture helper and private capture app are not shipped in the DMG.
