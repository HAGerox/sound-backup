# Screenshot

`home.png` is a native Retina capture (1520 × 1120) of the Sound Backup 0.1.0 packaged Tauri app at a compact 760 × 560 point window size. `home.webp` is its lossless web version.

Captured the actual app using the apps website's Cocoa view capture helper in an ignored private copy. No interface controls or connection statuses were fabricated. This machine had a saved QLab connection that was unavailable during capture; the other systems were not configured. No account names, addresses or personal paths appear in the published capture.

The injected capture helper and private capture app are not shipped in the DMG.
